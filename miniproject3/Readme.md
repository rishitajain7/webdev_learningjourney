# 🚀 FlowApp – Modern SaaS Landing Page

FlowApp is a modern and responsive SaaS landing page built using **HTML** and **Tailwind CSS v4**. The project focuses on creating a clean user interface with smooth animations, glassmorphism effects, and a fully responsive layout that adapts seamlessly across different screen sizes.

## ✨ Features

* Modern and responsive design
* Interactive hero section
* Animated statistics dashboard
* Features showcase
* Customer testimonials
* Call-to-action section
* Newsletter subscription form
* Glassmorphism UI
* Smooth custom animations
* Mobile-friendly layout

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS v4
* CSS3

## 🚀 Getting Started

1. Clone the repository
```bash
git clone https://github.com/rishitajain7/FlowApp.git
```
2. Navigate to the project folder
```bash
cd FlowApp
```
3. Install Tailwind CSS dependencies
```bash
npm install
```
4. Start the Tailwind CSS compiler
```bash
npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
```
5. Open `index.html` in your browser.
