# Hello World React App

This is a simple React application created using **React + Vite**.

## Features

* Simple React component
* Displays **Hello World!**
* Uses Vite for development

## Technologies Used

* React
* Vite
* JavaScript
* CSS

## Run the Project

```bash
npm install
npm run dev
```

Open the localhost URL shown in the terminal to view the application.

## Output

```text
Hello World!
```
