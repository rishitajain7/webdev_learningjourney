# Hello World React Application

## Problem Statement

Develop a basic "Hello World" React application.

## Description

This project is a simple React application that displays the text **"Hello, World!"** on the screen.

## Technologies Used

* React
* Vite
* JavaScript
* HTML
* CSS

## How to Run the Project

1. Install the required dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal in your browser.

## Output

The application displays:

**Hello, World!**
